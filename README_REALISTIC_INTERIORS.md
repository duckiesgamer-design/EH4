# Realistic classroom interior update

This version adds classroom ceilings, glazed windows with frames, wall-mounted teaching boards, desks with legs, student chairs, teacher desks, doors and handles, and ceiling LED panels with small local lights. Materials use generated tiled, concrete and wood grain textures, so no extra image downloads are needed.

The project uses Three.js from jsDelivr and should be opened through a local web server. The classroom contents are procedural approximations rather than a surveyed exact copy of Het Erasmus. For best performance on mobile, use a modern device and close other browser tabs.
